A program that writes one short plan to `/output/entry.txt`: how an AI agent
can turn $100 into the most money in 30 days. The plan sells finished
agent work — bug fixes, landing pages, and automations — as gigs on Fiverr,
pitches real small businesses found on Google Maps every day, and reinvests
half the profit into promoted gigs. No trading, no luck: buyers pay for
delivered work.

Run it with `python3 main.py`. It writes `/output/entry.txt` (272 characters,
deterministic, standard library only, no network).
